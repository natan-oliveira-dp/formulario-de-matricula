# 📝 Formulário de Matrícula - Estrelas do Amanhã

Projeto desenvolvido para prática de desenvolvimento web, utilizando formulários estilizados e responsivos.

## 🚀 Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox e variáveis CSS)

## 📌 Funcionalidades
- Seleção de campos obrigatórios com validação
- Seleção de turnos e matérias usando radio buttons personalizados
- Layout moderno e responsivo
